# ADR-0001 : Stack sans build

## Statut
Accepté

## Contexte
Le projet doit rester simple et déployable sans étape de compilation tant que ce n'est pas nécessaire.

## Décision
HTML + CSS + JS ES modules natifs. Pas de framework ni de bundler pour le moment.

## Conséquences
Simplicité, déploiement direct, mais limite de complexité future.
