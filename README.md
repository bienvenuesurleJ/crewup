# CREWUP

Plateforme pour trouver des coéquipiers, organiser des sessions et former des crews.
Développement par **12 étapes validées une à une** — voir [PROJECT_STATUS.md](PROJECT_STATUS.md).

## Lancer le projet

Prérequis : Node.js ≥ 20 (aucune installation de paquets).

```bash
npm run dev     # http://localhost:5173
npm run check   # vérifications automatiques
```

Guide de style : http://localhost:5173/dev/design-system.html
